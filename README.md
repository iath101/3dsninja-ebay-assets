# 3Ds Ninja eBay Assets

Static stylesheet and images referenced by 3Ds Ninja's eBay listing templates
(e.g. `style-16.css`, `images/ebay/<product>/<n>.jpg`).

**Not part of the Shopify storefront.** This repo exists purely so these
files have a stable public URL for eBay listing HTML to pull from, replacing
the old host at 3dsninja.com. Intended to be served via GitHub Pages on a
subdomain (e.g. `static.3dsninja.com`), keeping the exact same folder
structure and paths the old listings already reference — only the domain
changes.
